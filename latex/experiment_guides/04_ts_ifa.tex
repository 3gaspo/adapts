\section{Final architecture}
TS-IFA is a lightweight adapter around a frozen forecast backbone $F$.  All
quantities below are expressed after query-scale instance normalization.  For a
query history $x\in\mathbb R^L$, retrieved histories
$x^c_j\in\mathbb R^L$, retrieved futures $y^c_j\in\mathbb R^H$, and $K$
neighbors, define
\[
 p=F(x),\qquad p^c=F(x;\{x^c_j,y^c_j\}_{j=1}^K),\qquad
 n_j=F(x^c_j),\qquad e_j=y^c_j-n_j .
\]
An optional transformed frozen expert uses past-only covariates:
\[
 \phi(x)=\bigl(\operatorname{sgn}(x),\sqrt{|x|}\bigr),\qquad
 p^\phi=F(x;\text{past covariates } \phi(x)).
\]
No future value of $\phi$ is supplied.  A backbone that ignores past
covariates simply gives $p^\phi=p$.  This extraction is disabled by default,
so payloads created before this expert was introduced remain valid.

Independently, a learned transformed covariate may be enabled:
\[
 u_\psi=T_\psi(x)\in\mathbb R^H,\qquad
 c_\phi=\widetilde p^\phi+G_\phi([\widetilde p^\phi,u_\psi]),
 \qquad
 \widetilde p^\phi=
 \begin{cases}
 p^\phi,&\text{if the precomputed expert is enabled},\\
 p,&\text{otherwise}.
 \end{cases}
\]
Both $T_\psi$ and $G_\phi$ are MLPs trained on \Tone.  Thus the learned
covariate can be studied without rerunning extraction; enabling both options
uses the precomputed sign/root forecast as its anchor.

\subsection{Learned branches}
Residual attention retrieves errors from analogous \emph{states}, not merely
analogous histories:
\[
 q_r=[x,p],\qquad k^r_j=[x^c_j,n_j],\qquad v^r_j=e_j,
 \qquad
 z_r=A_r(q_r,\{k^r_j\},\{v^r_j\})\in\mathbb R^H,
\]
\[
 c_r=p+M_r([p,z_r]).
\]
There is one query token and $K$ neighbor tokens.  Thus the attention produces
one mixture over neighbors, not a separate attention distribution per forecast
horizon.

The memory branch reads retrieved horizons directly:
\[
 z_m=A_m(x,\{x^c_j\},\{y^c_j\})\in\mathbb R^H,\qquad
 c_m=W_m[p,z_m]+M_m([p,z_m]).
\]
Unlike $c_r$, $c_m$ is a direct forecast rather than a named residual
correction.  Its linear skip $W_m$ and nonlinear MLP jointly learn a mixture of
the vanilla forecast and retrieved horizons.

\subsection{Candidate-conditioned, unconstrained rooter}
The default four candidate forecasts are
\[
 (c_0,c_1,c_2,c_3)=(p,p^c,c_r,c_m).
\]
If either transformed option is enabled, the fifth candidate is inserted:
\[
(c_0,c_1,c_2,c_3,c_4)=(p,p^c,c_\phi,c_r,c_m),
\]
The rooter is deliberately not given hand-designed distances, neighbor
dispersion, or retrieval statistics.  It learns its own retrieval state:
\[
 z_g=A_g(x,\{x^c_j\},\{x^c_j\})\in\mathbb R^D.
\]
Each active candidate has a learned type token $\tau_j\in\mathbb R^D$.  One MLP
$S_\theta$, shared across candidates, produces an entire horizon-wise
coefficient vector:
\[
 a_j=S_\theta\!\left(
 \operatorname{LN}(z_g),\operatorname{LN}(p),
 \operatorname{LN}(c_j),\operatorname{LN}(\tau_j)
 \right)\in\mathbb R^H,
\]
\[
 \boxed{\quad \widehat y
 =p+\sum_{j=0}^{J-1}a_j\odot c_j,\qquad J\in\{4,5\}.\quad}
\]
The coefficients are unconstrained: there is no sigmoid, softmax, or convexity
constraint.  This retains the extrapolation ability observed for ridge
baselines.  The vanilla fallback is $a_j=0$ for every $j$.  A direct fallback
to candidate $c_j$ is representable by $a_0=-1$, $a_j=1$, and all other
coefficients zero.

\section{Initialization and optional regularization}
With vanilla-anchoring initialization enabled,
\[
 M_r^{\rm out}=0,\qquad W_m=[I_H\;\;0],\qquad M_m^{\rm out}=0,
 \qquad G_\phi^{\rm out}=0,
 \qquad S_\theta^{\rm out}=0.
\]
Consequently $c_r=c_m=\widehat y=p$ exactly at step zero; when the learned
transformed branch is enabled, $c_\phi=\widetilde p^\phi$.  This initialization
is optional; disabling it restores the standard PyTorch initialization.

The branches are trained on \Tone with
\[
 \mathcal L_B=
 \ell_n(c_r,y)+\ell_n(c_m,y)
 +\mathbb I_{\rm learn\text{-}\phi}\ell_n(c_\phi,y)
 +\lambda_V\{\ell_n(c_r,p)+\ell_n(c_m,p)
 +\mathbb I_{\rm learn\text{-}\phi}\ell_n(c_\phi,p)\},
\]
where $\ell_n$ is normalized MSE.  After branch training, all branch weights
are frozen.  The neural rooter is trained on \Ttwo with
\[
 \mathcal L_R=
 \ell_n(\widehat y,y)
 +\lambda_V\ell_n(\widehat y,p)
 +\lambda_2\frac1{JH}\sum_{j,h}a_{j,h}^2
 +\lambda_S\frac1{J(H-1)}
   \sum_{j,h=1}^{H-1}(a_{j,h+1}-a_{j,h})^2.
\]
The three regularizers are independent and optional: setting the corresponding
coefficient to zero removes it.  Defaults are
$\lambda_V=\lambda_2=\lambda_S=10^{-2}$.

\section{Separate ridge rooter}
The frozen \Tone branches permit a rooter-only comparison on exactly the same
candidate bank.  A horizon-wise, no-intercept ridge rooter is fitted from exact
\Ttwo sufficient statistics:
\[
 A_{\rm ridge}=\arg\min_{A\in\mathbb R^{J\times H}}
 \sum_{i,h}\left[
 y_{i,h}-p_{i,h}-\sum_{j=0}^{J-1} A_{j,h}c_{i,j,h}
 \right]^2+\alpha\lVert A\rVert_F^2.
\]
Candidate columns are RMS-scaled before solving and mapped back afterward.
The fit uses all selected \Ttwo examples and has exactly $JH$ learned
coefficients: $4H$ by default and $5H$ with a transformed candidate.  It does
not see \Tthree.

\section{Training and evaluation protocol}
Extraction pools \Tone+\Ttwo and assigns the final 20\% of whole query dates
to \Ttwo.  The staged pipeline is:
\[
 \text{\Tone: train }(c_r,c_m[,c_\phi])
 \quad\longrightarrow\quad
 \text{\Ttwo: fit ridge and neural rooters with branches frozen}
 \quad\longrightarrow\quad
 \text{\Tthree: evaluate once}.
\]
Each optimization epoch draws one random batch; deterministic full-\Ttwo
diagnostics retain \code{--valid-eval-freq} and interval-average logs retain
\code{--logging-eval-freq}.  There is no \Tthree checkpoint selection or refit.
The neural and ridge rooters are deliberately trained independently, so the
same branch checkpoint can support additional rooter experiments.

The launcher \code{ts\_ifa.slurm} writes the \Tone branch checkpoint, neural
checkpoint, ridge coefficients, histories, and complete \Tthree predictions.
Predictions are written batch by batch as separate NumPy arrays indexed by the
sole current \code{prediction\_manifest.json}; no aggregate prediction
checkpoint is retained.  \code{result\_manifest.json} is written last as the
completion marker.
The metric artifact always reports vanilla, context, residual, and memory
candidates, and reports transformed performance only when that candidate is
active; it also reports the ridge-rooted system and full neural TS-IFA.

parameters.

\section{Interpretation}
Report every active candidate, ridge-rooted TS-IFA, and neural TS-IFA together.
This separates candidate quality from rooter quality and tests whether the
471k-parameter conditional rooter earns its capacity over the 256-coefficient
default ridge alternative (320 with the transformed candidate).  Attention
weights remain diagnostics rather than causal feature importance.
